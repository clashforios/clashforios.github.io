第三步：核心配置——让服务器跑起来

这是整个使用流程中最关键的一步。v2rayNG 支持多种添加服务器的方式，这里为你梳理了三种最常用的方法：

方法一：手动输入（适合熟悉配置信息的用户）

点击界面右上角的“+”号，选择“手动输入[VMess]”或根据你的协议类型选择相应的选项。你需要填写以下核心信息： - 地址 (Address)：你的服务器 IP 或域名。 - 端口 (Port)：服务器对外服务的端口号。 - 用户ID (UUID)：一串形如 xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx 的唯一标识符。 - 额外ID (AlterId)：通常为 0 或 64，需与服务器端保持一致。 - 加密方式 (Security)：建议选择 auto 或 aes-128-gcm，确保传输层安全。

如果你使用的是 VLESS 或 Trojan 协议，填写逻辑类似，只是字段名称略有不同。为了省事，你可以优先复制粘贴服务器提供商给你的 JSON 格式链接。

方法二：导入订阅链接（懒人福音）

如果你购买了付费服务或使用了机场订阅，这种方式最为高效。复制服务商提供的“订阅地址”。回到 v2rayNG，点击右上角的“+”号，选择“导入订阅地址”，粘贴链接并确认。应用会自动拉取服务器列表并填充，你只需在列表中点击选择一个节点即可。

方法三：扫码或粘贴分享链接

很多服务商为了方便，会提供二维码或类似 vmess:// 开头的分享链接。在 v2rayNG 主界面，点击右上角的“扫码”图标，直接扫描二维码即可完成添加。如果是文本链接，可以直接复制，打开应用时通常会弹出提示，点击导入即可。

配置好服务器后，先别急着连。v2rayNG 的强大之处在于其灵活的路由功能。点击左上角的抽屉菜单，进入“设置” -> “路由设置”。

  • 路由模式：这里有几种预设模式，最推荐的是“绕过局域网及大陆地址”或“全局直连”。前者意味着访问国内网站时不走代理，速度快；访问国外网站时才走代理，兼顾速度与自由。后者则所有流量都走代理，适合特定场景。
  • 自定义规则：对于进阶玩家，你可以在“规则”中添加自定义域名或 IP 段，实现精细化控制。例如，你可以强制某些视频网站走代理以解锁区域限制，或者让某些小众应用直连以避免代理干扰。

合理配置路由规则，能让你的网络体验丝滑流畅，这也是 v2rayNG 相比简单 VPN 的一大优势。

第五步：连接与测试

一切准备就绪，回到主界面。点击你刚刚添加的服务器卡片，选中它（卡片会高亮），然后点击右下角的圆形“连接”按钮。状态栏会显示一个钥匙图标或 VPN 图标，表示系统代理已开启。

此时，打开你的浏览器，尝试访问一个之前无法打开的网站。如果顺利加载，恭喜你，已经成功了！如果无法访问，别急，可以尝试以下排查： 1. 检查服务器信息是否填写有误。 2. 切换一下“连接方式”，比如从 TCP 改为 WS（WebSocket）。 3. 查看 v2rayNG 的日志输出，看是否有报错信息。

使用这类工具时，安全意识不能少。 - 选择可信的服务提供商：你的流量会经过你所选的服务器，因此请务必选择信誉良好、承诺不记录日志的服务商。 - 启用混淆与 TLS：在服务器配置中，如果支持，建议开启 TLS 加密和混淆参数。这不仅能降低被墙的风险，也能防止你的流量特征被深度包检测（DPI）识别。 - 不要用于非法活动：技术本身是中性的，但使用技术的行为需要遵守当地法律法规。请将 v2rayNG 用于正当的学习、工作和信息获取。

FAQ

Clash 如何通过规则文件优化节点分流？
Clash 支持自定义规则文件，可按域名、IP 或应用类型分流流量。结合策略组使用，可将不同类型的流量自动分配到最优节点，提高访问速度和网络稳定性，减少延迟和卡顿。
如何在 Android 手机上使用 Clash for Android？
Clash for Android 是专为移动设备开发的客户端，安装后导入订阅链接即可使用。用户可设置代理模式（全局、规则、自定义）并查看实时流量信息。它的电量消耗较低，适合长期后台运行。
为什么某些网站在通过代理后登录会频繁要求二次验证？
代理会改变访问 IP 与地理位置，目标站点可能检测到异常登录并触发验证码或二次验证。建议对常用账户使用白名单 IP 或在代理配置中对特定站点设置直连来避免频繁验证。
Hysteria2 多路复用对短连接性能有何提升？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适合高频短连接场景，如游戏和即时通讯，可提高吞吐量和连接稳定性，优化整体网络体验。
Clash 节点延迟检测如何帮助分流？
Clash 会定期测试节点延迟，并结合策略组自动选择最优节点处理流量。避免访问高延迟或失效节点，提高网页浏览、视频播放和游戏速度及稳定性，优化整体网络体验。
Clash 的规则订阅更新有哪些注意事项？
Clash 订阅更新需保证网络畅通，规则文件格式正确，并与客户端版本兼容。建议定期更新规则以获得最新节点和分流规则，同时注意避免频繁刷新造成性能问题。
WinXray 是否支持多订阅源？
支持。用户可导入多个订阅 URL，每个订阅源独立管理。通过切换订阅源或合并策略组，可灵活管理节点，实现不同地区或用途的线路分配。
SSR 的协议插件如何增强连接稳定性？
SSR 的协议插件可以增加流量的伪装特性，模拟常见协议或浏览器行为，从而降低被识别和封锁的风险。这对不稳定网络或高封锁环境尤其有帮助。
PassWall2 如何自动切换最佳节点？
通过延迟测速和策略组设置，PassWall2 可自动选择延迟最低的节点处理流量。用户无需手动切换节点，保证网页、视频和游戏流量的速度和稳定性，提高整体网络体验。
VMess AEAD 加密在高封锁网络中有何优势？
AEAD 加密能防止流量被篡改或重放，并隐藏流量特征。在高封锁网络中，使用 AEAD 可以提高节点稳定性和长期可用性，同时确保数据安全和隐蔽性。
